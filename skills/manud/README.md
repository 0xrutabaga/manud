# manud — MANUD (มะนุด) Skill folder (3.1.0, formerly thai-humanizer V3.0.0)

Agent Skill สำหรับเกลาข้อความภาษาไทยที่มีอยู่แล้วให้อ่านเป็นธรรมชาติและเหมาะกับบริบท โดยมุ่งรักษาข้อเท็จจริงและความสัมพันธ์ระหว่างข้อมูล ใช้ได้กับ Agent ที่รองรับ Agent Skills เช่น Codex, Claude Code และ Google Antigravity โดยทำงานผ่านโมเดลที่ Agent ใช้อยู่แล้ว ไม่ต้องเชื่อมต่อ API เพิ่มเฉพาะสำหรับ MANUD

## V3 เปลี่ยนอะไร

V3 เปลี่ยนจาก "คู่มือสำนวน" เป็น **กระบวนการตัดสินใจเชิงบรรณาธิการ** ก่อนลงมือแก้:

| Stage | สิ่งที่ทำ |
| :--- | :--- |
| A — Context | ระบุประเภทงาน (9 ประเภท) ผู้อ่าน ภาษาพูด/เขียน น้ำเสียงผู้เขียน และรูปแบบที่ต้องคงไว้ |
| B — Fidelity contract | จดข้อเท็จจริงที่ต้องรอด **พร้อมสิ่งที่มันผูกอยู่** (ราคาไหนของสินค้าไหน ใครทำอะไร เงื่อนไขไหนของข้อเสนอไหน) |
| C — Transformation | แก้ลำดับคำ จังหวะ ศัพท์ การเชื่อมความ ลำดับข้อมูล โดยไม่เติมอนุภาค สแลง อีโมจิ หรือคำทับศัพท์โดยอัตโนมัติ |
| D — Edit level | เลือก keep / light / substantial ก่อนเขียน ข้อความที่ดีอยู่แล้วคืนเดิมได้ |
| E — Quality gate | เทียบกับต้นฉบับหนึ่งรอบ แก้ได้อีกไม่เกินหนึ่งครั้ง ถ้าไม่แน่ใจให้แจ้ง ไม่เดา |

นโยบายเฉพาะใหม่:
- **เอกสารเทคนิค / release notes** — คงหัวข้อ รายการ code block คำสั่ง endpoint version และคำเตือน ห้ามแปลงเป็นร้อยแก้วเล่าเรื่อง ([TECHNICAL_DOCS.md](references/TECHNICAL_DOCS.md))
- **โพสต์โซเชียล / ผู้ก่อตั้ง** — ตัดคำลงท้ายแบบหนังสือราชการ (เช่น `นำข้อมูลนี้ไปประกอบการพิจารณา`) ไม่ยัด CTA ความตื่นเต้น รีวิว หรือประวัติผู้ก่อตั้งที่ต้นฉบับไม่มี ([SOCIAL_MEDIA.md](references/SOCIAL_MEDIA.md))

รายละเอียดทั้งหมดอยู่ใน [CHANGELOG.md](CHANGELOG.md)

## ตัวตรวจ `check_preservation.py` (3.0.0)

```bash
python scripts/check_preservation.py original.txt rewritten.txt --context technical --terms-file terms.txt --json
```

ผลแบ่งเป็น 3 ระดับ:

1. **Deterministic failures** — ตัวเลข (อารบิก/ไทย) URL อีเมล version endpoint identifier code block / inline code protected terms จำนวนคำปฏิเสธ เครื่องหมายเวลาสไลด์ และ (เมื่อ `--context technical`) การหายของหัวข้อ รายการ ตาราง คำเตือน
2. **Suspected semantic violations** — ราคา/จำนวนสลับเจ้าของ คำปฏิเสธกลับขั้ว เงื่อนไขหาย คำสงวนท่าทีหาย สถานะ "วางแผน" กลายเป็น "เสร็จแล้ว" ผู้กระทำเปลี่ยน เหตุผลถูกแต่งเพิ่ม ชื่อ/ความสามารถใหม่ที่ต้นฉบับไม่มี รีวิวหรือประสบการณ์ส่วนตัวที่แต่งขึ้น (ต้องให้คนอ่านยืนยัน)
3. **Stylistic warnings** — คำโปรย AI ที่เพิ่มเข้ามา ภาษาราชการในโพสต์โซเชียล CTA ยัดเยียด การแก้เกินจำเป็นกับข้อความที่ดีอยู่แล้ว (`--context minimal`) การตัดทอนมาก

Exit code: `0` ผ่าน, `1` ไม่ผ่าน, `2` อ่านไฟล์ไม่ได้ ระดับ 2 ทำให้ไม่ผ่านโดยปริยาย (`--semantic-advisory` เพื่อรายงานอย่างเดียว) ระดับ 3 ไม่ผ่านเฉพาะเมื่อใช้ `--strict`

**ข้อจำกัดสำคัญ:** สคริปต์นี้ **พิสูจน์ไม่ได้** ว่าความหมายถูกรักษาไว้ มันเทียบรายการ token และรูปแบบบางอย่างเท่านั้น ไม่ได้ parse ไวยากรณ์ไทย จับคู่ราคากับสินค้าได้เฉพาะเมื่ออยู่ใกล้กัน (ชื่อภาษาไทยต้องใส่ใน `--terms-file`) และอาจพลาดหรือแจ้งเตือนเกินได้ ผล PASS หมายถึง "ไม่พบรูปแบบที่ตรวจ" เท่านั้น
