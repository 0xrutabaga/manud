## How the mascot was made

Little Manud was made under the direction of the MANUD maintainer, with AI tools at two steps:

1. **Reference images** were generated with an AI image model (`gpt-image-2`, through Meshy). The maintainer chose one.
2. **The final vector** was rebuilt as clean geometric shapes by an AI coding assistant (Claude), working from that reference, with a redesigned loop and exact brand colors. It was built with the parametric script in `mascot-v1.0/source/`, and every step was reviewed and approved by the maintainer.

The SVG files contain no pixels from the generated images. Provenance details are in `mascot-v1.0/MANIFEST.md`.

## Integrity

These files are frozen. Check them with:

```bash
cd assets/brand/mascot-v1.0 && sha256sum -c SHA256SUMS
```

The SVG files use CRLF line endings, and the repository's `.gitattributes` marks this folder `-text` so Git never converts them. Don't re-save these files in an editor; changes need a new version folder.
